# OWNOVA Next.js App Router

Converted from the supplied static HTML without changing the visual direction.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000. Marketplace route: `/explore`.

## Architecture

- `src/domain`: entities
- `src/application`: use cases
- `src/infrastructure`: repositories
- `src/components`: reusable presentation components
- `src/app`: Next.js App Router routes

All system-facing route names and code identifiers are in English.
